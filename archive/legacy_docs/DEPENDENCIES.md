# Dependencies

MLIRBench relies on the following major software components.

## Core Framework

- LangGraph
- LangChain

## LLM Providers

- OpenAI
- Anthropic
- Gemini
- OpenRouter

## Compiler Infrastructure

- LLVM / MLIR
- Torch-MLIR
- IREE Compiler
- IREE Runtime

## Validation Service

- FastAPI
- Uvicorn

## Numerical Libraries

- NumPy
- SymPy

Install all dependencies using:

```bash
pip install -r requirements.txt
```
